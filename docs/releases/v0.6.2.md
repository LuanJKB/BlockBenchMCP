# BlockBench MCP v0.6.2

## 修复与增强

- **首次安装启动确认**：修复 Blockbench 先执行 onload、后执行 oninstall 导致首次安装不弹启动确认、重载后才弹窗的问题。安装回调会取消旧的自动启动任务并重新安排确认；增加内存安装标记、卸载取消定时器及失效弹窗回调保护。
- **Bedrock 原生新建**：支持 bedrock / bedrock_old，无需 GeckoLib；可设置 uv_mode、geometry_name 和贴图尺寸，保留已有项目。格式不支持的 UV 模式会在新建前拒绝。
- **骨骼与几何编辑**：修复组节点误用方块撤销接口引发的 getUndoCopy 错误；变换和可见性立即刷新；整组变换包含子树并避免父子重复变换，修正枢轴旋转与旋转复合。
- **预览取景**：离屏正交相机按可见模型边界取景，计入骨骼旋转和膨胀量，不移动模型或改变用户相机。
- **桌面文件操作**：支持插件作用域内的 require，修复 Node modules unavailable；保留模块权限、目录授权和显式覆盖保护。

## 安装

下载附件 **blockbench_mcp.js**，在 Blockbench 桌面端（最低 5.1.0）通过 **File → Plugins → Load Plugin from File** 加载。已有用户需要重新加载插件，新代码才会生效；首次安装会先询问是否启动 MCP。桌面模块权限仍需按提示授权。

SHA256SUMS.txt 提供插件附件的 SHA-256 校验值。GitHub 自动生成的源码压缩包不是可直接加载的插件文件。

## 验证

- 全量 69 项测试：37 项共享契约测试、20 项 Bedrock 宿主回归测试、12 项启动生命周期测试。
- 类型检查、插件构建及 JavaScript 语法检查。
- 宿主回归测试使用模拟接口；本次发布不宣称已完成真实桌面端端到端验收，且未在用户模型上执行破坏性测试。

## English summary

Fix first-install startup prompting, add native Bedrock project creation, correct bone undo and subtree transformations, refresh edited geometry immediately, fit offscreen captures to visible model bounds, and resolve desktop modules through the plugin-scoped loader. Existing projects, permission prompts, scoped file access, and explicit overwrite protection are preserved.
